# ONG Conecta Futuro

Projeto acadêmico de um site para a ONG Conecta Futuro, voltada ao acesso à educação de qualidade para crianças e jovens em situação de vulnerabilidade.

A atividade pratica a estruturação de páginas web com HTML semântico, navegação, imagens e formulários.

## Estrutura

```text
.
├── README.md
├── html/
│   ├── index.html
│   ├── projetos.html
│   └── cadastro.html
└── imagens/
    └── acao-social.jpg
```

## Como visualizar

Abra `html/index.html` diretamente em um navegador. Não é necessário instalar dependências ou iniciar um servidor.

## Estado do desenvolvimento

- A página inicial apresenta a ONG, uma imagem de ação social e informações de contato.
- As páginas de projetos e cadastro ainda precisam ser adaptadas ao conteúdo da ONG.
- O título da aba da página inicial ainda precisa ser atualizado para o nome da ONG.
- O formulário de cadastro é demonstrativo e não possui serviço de armazenamento de dados.

## Tecnologias

HTML5. A estrutura atual não contém arquivos CSS ou JavaScript, backend ou banco de dados.
