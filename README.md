# Brasil em Foco — Atividade da faculdade

Projeto acadêmico desenvolvido em HTML para praticar a estruturação de páginas web com elementos semânticos, links, imagens e formulários.

## Páginas

- **Início:** portal com notícias sobre tecnologia, educação e meio ambiente e links para as fontes.
- **Projetos:** apresentação do projeto e dos objetivos da atividade.
- **Cadastro:** formulário demonstrativo com dados pessoais e áreas de interesse. Não envia nem armazena dados.

## Estrutura

```text
html/
  index.html
  projetos.html
  cadastro.html
img/
  data-center.jpg
  logo.png
```

## Como abrir

Abra `html/index.html` em um navegador e utilize os links de navegação para acessar as outras páginas. Não é necessário instalar dependências ou iniciar um servidor.

## Tecnologia

HTML5, sem CSS, JavaScript ou banco de dados.

## Finalidade acadêmica

Atividade prática da faculdade para exercitar organização de arquivos e construção de páginas web. As notícias da página inicial possuem links para a Agência Brasil. Os materiais de terceiros permanecem sujeitos aos direitos de seus respectivos titulares.
